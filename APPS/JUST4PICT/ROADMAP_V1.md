# JUST4PICT — Roadmap v1.0

## Vision

JUST4PICT debe ser la app mas rapida para "mejorar un lote de imagenes" sin conocimiento tecnico.

## v0.1 (MVP operativo)

- Batch estable por archivo/carpeta.
- Presets automaticos listos para uso diario.
- Export multiple formato con calidad configurable.
- Integracion en JUST4ALL como subapp instalable.

## v0.2 (productividad)

- Preview manual con `Enhance` y comparativa estable.
- Visor ampliado por doble click para inspeccion de diferencias.
- Historial de lotes y reaplicar ultimo preset.
- Cancelar/reanudar batch.
- Presets personalizados guardados localmente.

## v0.3 (quality boost)

- Pipeline de retrato `PRO` refinado, protegido para piel y ya usable como baseline.
- `AUTO` heredando correctamente `Retrato` cuando detecta cara.
- `AUTO` con mejor deteccion de paisaje vertical y mejor base para nocturna.
- Resize inteligente por destino (web, redes, ecommerce).
- Deteccion automatica de documento + mejora de legibilidad.
- Auto white balance y correccion de dominantes de color.

## v0.4 (pro)

- Procesamiento paralelo configurable (80% CPU por defecto).
- Export recipes (preset + formato + naming).
- CLI simple para automatizaciones (`just4pict-cli`).

## v1.0

- Flujo robusto para lotes grandes.
- UX pulida, accesible y keyboard-first.
- Pipeline de release con checksums, firma y notarizacion.
- Publicacion estable con DMG versionado.
