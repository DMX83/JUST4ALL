Third-party licenses

Just4Folders does not bundle third-party binaries. It uses system frameworks and, optionally, an AI service with the user’s key.

Apple frameworks

SwiftUI, AppKit, PDFKit, ImageIO, CoreImage, Vision, UniformTypeIdentifiers, Security and SQLite3 (system library). Their use is governed by the macOS and Xcode licenses.

Optional services

  • DeepSeek API — optional, with the user’s key. No binary is redistributed. Subject to the provider’s terms.

Retired components

Earlier versions of the suite used fuse-t/ntfs-3g, Real-ESRGAN/ncnn and PyMuPDF. They are no longer part of Just4Folders: the App Store sandbox does not allow running external binaries, and GPL ffmpeg is not compatible with App Store distribution.
